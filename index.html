Настройка REST API — можно оставить пустой до развёртывания сервера

Ожидаемый ответ GET /api/leads: JSON-массив записей или объект {"items":[...]}. Кнопка обновления вызывает только указанный API. Сам сканер рекламы пока не подключён.

Важно о безопасности. Не размещай секреты рекламных API в HTML-файле. Для реальной базы сервер должен проверять доступ, хранить секреты в переменных окружения и отдавать данные по HTTPS.
